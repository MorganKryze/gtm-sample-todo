# Language and copy guideline

> When to read: implementer and reviewer when a diff changes CLI output or error text.

- **Language:** English only; strings live next to the code that prints them (no i18n layer for
  a CLI this size).
- **Errors:** lower case, no final period, prefixed `todo: ` by bin/todo.js (e.g. `no todo #9`,
  `a todo needs some text`).
- **Copy:** plain words, one term per concept (`todo`, `add`, `done`, `list`).
- Never a word that judges the user (`nothing to do`, not `you have no tasks`).
